2. ATURAN PENTING BOOTSTRAP SUPER ADMIN (TERMASUK RESET PASSWORD V2)
==============================================================================
- BOOTSTRAP_ADMIN_* digunakan untuk membuat Super Admin pertama atau mereset
  password Super Admin jika email tersebut sudah ada di tabel users.
- Pada V2, ON DUPLICATE KEY UPDATE juga memperbarui password_hash = VALUES(password_hash),
  role = 'super_admin', dan status = 'approved'.
- Setelah login Super Admin berhasil:
  WAJIB HAPUS BOOTSTRAP_ADMIN_PASSWORD dari Environment Variables Hostinger.
  BOOTSTRAP_ADMIN_EMAIL dan BOOTSTRAP_ADMIN_NAME juga boleh dihapus setelah bootstrap selesai.

==============================================================================
3. VARIABEL YANG HARUS DIHAPUS DARI ENVIRONMENT VARIABLES WEB HOSTINGER
==============================================================================
Hapus 5 variabel berikut dari Environment Variables website Hostinger:
- APK_KEYSTORE_PASSWORD
- APK_KEY_PASSWORD
- APK_KEY_ALIAS
- APK_PORTAL_URL
- APK_FALLBACK_PORTAL_URL

Alasan: Kelima variabel APK_* tersebut khusus untuk proses build APK Android lokal/CI,
bukan kebutuhan runtime website Node.js di Hostinger. Jangan menaruh kredensial signing
APK di environment website.
